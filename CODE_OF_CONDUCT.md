# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and not the person, and no harassment of any kind. This applies in issues, pull requests and any other project space.

## Reporting

If someone's behaviour here is a problem, contact the maintainer privately through their GitHub profile, [@gamparohit](https://github.com/gamparohit), or use GitHub's own "Report content" option on the comment or issue. Reports are kept confidential.

The maintainer may edit or remove comments, commits, issues and pull requests that break this code, and may block repeat offenders.
